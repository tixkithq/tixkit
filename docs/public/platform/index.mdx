The Tixkit Platform API is the developer-facing capability inside Tixkit Cloud. It shares the same event, inventory, checkout, order, attendee, webhook, workflow, migration, OpenAPI, and SDK contracts as the rest of Tixkit.

> **Availability:** hosted Platform API access is planned for an experimental private beta. Public API contracts and SDK source are available for evaluation, but production Cloud credentials and support terms are not generally available.

## Make a safe first integration

1. Follow the [hosted Platform API quickstart](/platform/quickstart) if you have a private-beta invitation, or read it to understand the intended credential and environment flow.
2. Read the [API fundamentals](/developers/api-fundamentals), including tenant scope, authentication, permissions, idempotency, pagination, errors, and retries.
3. [Make the first API call](/getting-started/first-api-call) with the narrowest useful credential scope.
4. Choose a [supported SDK](/sdks/javascript) or use the generated OpenAPI contract directly.
5. [Configure webhooks](/developers/webhooks/setup), verify every signature, and make consumers idempotent.
6. Add the [embedded widget](/developers/widget/embedding) only after the server-side contract and failure behavior are understood.

## Agent connections

Third-party agents connect through the same Platform API. API version `2026-07-26` exposes experimental sponsor-bound principals, delegation, short-lived explicit agent authentication, an isolated session surface, server-derived `event.publish` action preparation with immutable dry-run evidence, short-lived digest-bound human approval, action-bound revocation and durable approved execution. Third-party conformance remains in progress. Read the [agent Platform API guide](/platform/agent-platform) for the implemented boundary and current private-beta limitations.
