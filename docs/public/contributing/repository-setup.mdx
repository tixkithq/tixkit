Clone the repository, enter its root, and preserve any existing working-tree changes before editing.

```bash
bun install --frozen-lockfile
cp .env.local.example .env.local
bun run setup:check -- --mode local
bun run quickstart -- --no-open
```

The quickstart remains in the foreground and starts infrastructure, migrations, API, worker, checkout, admin, docs, and sample data. Use a second terminal for focused tests.

## Work safely

- Read the relevant package README, canonical guide, and nearby tests before changing a contract.
- Use repository search and focused source inspection to trace exact symbols and runtime strings.
- Preserve unrelated dirty-worktree changes; never reset or reformat them to simplify a task.
- Keep API, OpenAPI, SDKs, dashboard types, examples, docs, and tests synchronized in one change.

Stop the foreground quickstart with Control-C and verify its managed processes exit.
