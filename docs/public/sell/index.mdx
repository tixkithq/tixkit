Tixkit gives organizers one workflow for event setup, ticket inventory, checkout, orders, attendees, messaging, reporting, and event-day operations.

> **Availability:** the managed Tixkit Cloud organizer experience is planned for an experimental private beta. It is not generally available, and this documentation does not promise hosted access, support terms, or a launch date.

## Start with a complete test event

1. Follow the [Cloud organizer quickstart](/sell/quickstart) if you have a private-beta invitation, or read it to understand the intended hosted journey.
2. [Create your first event](/getting-started/first-event), including ticket types and availability.
3. [Complete a test checkout](/getting-started/test-checkout) before publishing or accepting live payments.
4. Review [orders and fulfillment](/operators/orders), [attendee records](/operators/attendees), and [refund behavior](/operators/orders/refunds).
5. Prepare [check-in](/operators/check-in), [box office](/operators/box-office), team permissions, and incident ownership before event day.

## Operate the event

Use the organizer dashboard for event configuration, schedules, ticket products, checkout forms, orders, attendees, messaging, and reports. Each operational guide identifies current stability and any provider-dependent proof that remains.

Managed organizer agents are also planned for an experimental private beta. Their initial scope is read, recommend, prepare, and execute only after approval; buyer purchasing and unrestricted delegated autonomy are outside that release.
