Events use a versioned envelope. Delivery is at least once: receivers must verify signatures, reject stale timestamps, and deduplicate by stable event ID. Ordering is not a global guarantee across endpoints or event types.

Tixkit retries non-2xx/activity failures with bounded exponential backoff and marks exhausted deliveries dead-lettered. Replay requires an active, idempotent receiver.
