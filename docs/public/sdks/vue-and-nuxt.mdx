```bash
bun add @tixkit/vue @tixkit/js
```

In Nuxt, import `createTixkitClient` from `@tixkit/vue/server` inside `server/` code and read the key from private runtime config. Do not expose it through `runtimeConfig.public`.

Client exports are for public checkout/widget behavior. Pass public event and brand identifiers from a server response rather than a privileged client instance.

The runnable Nuxt fixture is `apps/sdk-nuxt-demo`. Its README and build must remain synchronized with this guide and the SDK package exports.
