<SdkGuide sdkId="astro" />

```bash
bun add @tixkit/astro @tixkit/js
```

Use `createTixkitClient` from `@tixkit/astro/server` in endpoints, middleware, actions, or server-rendered pages. A fully static page cannot safely embed a secret key; fetch privileged data during a controlled build only when that exposure model is appropriate, or use server output.

The package includes server checkout-form and webhook-endpoint helpers. Preserve raw request bytes for signature verification.

Run `apps/sdk-astro-demo` to verify the current Astro integration and webhook route before copying it into an application.
