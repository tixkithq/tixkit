<SdkGuide sdkId="flutter" />

Add `tixkit_flutter` according to the package README and pubspec source used by your distribution model.

The SDK provides `TixkitScannerClient`, scanner storage contracts, checkout handoff, public event pages, resale behavior, and Flutter UI components. Production scanner credentials require platform-backed secure storage; `TixkitMemoryScannerStorage` is suitable for controlled tests, not durable secret storage.

Validate camera permission denial, duplicate/wrong-event scans, offline manifest expiration, background/resume behavior, and synchronization failure. Use `packages/sdk-flutter/example` and `apps/sdk-flutter-demo` as executable fixtures.
