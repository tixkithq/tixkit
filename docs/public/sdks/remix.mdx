<SdkGuide sdkId="remix" />

```bash
bun add @tixkit/remix @tixkit/js
```

Import `createTixkitClient` from `@tixkit/remix/server` in loaders, actions, and server utilities. Use private process environment values and never return the key from a loader.

The package provides server checkout-form helpers and a Remix checkout action. Validate write actions with idempotency and explicit error mapping; do not treat a redirect as proof a durable order completed.

Use `apps/sdk-remix-demo` as the runnable integration fixture and keep its environment contract aligned with this guide.
