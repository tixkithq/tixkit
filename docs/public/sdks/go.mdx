<SdkGuide sdkId="go" />

```bash
go get github.com/tixkithq/tixkit-go
```

Construct the client with `tixkit.NewClient` and a server-side key. Pass request contexts with deadlines and preserve typed API errors and request IDs. Use `NewCursorIterator` for paginated operations instead of modifying cursor values.

Keep keys in the service secret manager and redact authorization headers from HTTP tracing. The runnable source at `packages/sdk-go/examples/checkout` demonstrates the current API shape; run the module tests before copying an example into production.
