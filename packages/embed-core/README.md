# `@tixkit/embed-core`

Public Embed Contract v1 for Tixkit. The package has no runtime dependencies and is safe in browsers, Node.js, SSR, CLIs, and documentation builds.

It exports typed custom-element configuration, versioned lifecycle and `postMessage` contracts, strict validators, a stable error taxonomy, HTML/framework snippet generation, feature-derived CSP profiles, platform instructions, and safe theme tokens.

Production snippets must set an immutable `widgetScriptUrl`; the default URL is for local development and examples only.
